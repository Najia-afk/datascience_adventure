Production Blockchain Security

Bubble

Blockchain Investigation & Analytics Platform

Production-grade blockchain investigation platform for tracking illicit fund flows, managing crypto fraud cases, and monitoring suspicious wallets across multiple EVM networks. Features interactive graph exploration, Sankey diagrams, real-time wallet monitoring, and automated risk scoring.

View on GitHub

Tech Stack

Backend Flask 3.1 + Gunicorn
ORM SQLAlchemy 2.0
Database PostgreSQL 15
Task Queue Celery 5.6 + Redis
APIs REST + GraphQL (Strawberry)
Visualization vis.js — Interactive Graphs
Blockchain Multi-chain EVM (ETH, BSC, Polygon, Base)
Deployment Docker Compose — Dev + Prod

Key Features

🔍

Investigation Management

Create and manage fraud investigations with full status workflows, multi-chain support, and wallet classification

📊

Interactive Graph Explorer

Transaction flow visualization powered by vis.js with full-page views, Sankey diagrams, and dynamic filters

🔔

Real-time Monitoring

Suspect wallet tracking, activity alerts for mixer deposits and bridge transfers, automated risk scoring

💰

Loss Calculation

Real-time USD valuation from on-chain transfers and token prices with estimated loss totals per investigation

🏷️

Wallet Classification

Automatic categorization of wallets: victims, suspects, exchanges, bridges, mixers — with ML-based scoring

🛠️

Developer APIs

REST API + GraphQL with Swagger docs, GraphiQL explorer, and async Celery workers for distributed processing
