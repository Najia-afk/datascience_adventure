Aria Blue

Autonomous AI Agent Platform — Thinks Like a CEO

Aria is an autonomous AI agent that analyzes tasks, delegates to specialized focus personas, runs parallel roundtable discussions across domains, and synthesizes results — all on a self-driven work cycle with goal tracking, persistent memory, and full observability. Built on a native Python engine with multi-model LLM routing via LiteLLM.

Tech Stack

AI Gateway aria_engine — native Python orchestration
LLM Router LiteLLM — multi-model routing, auto failover
Local Inference MLX — Apple Silicon Metal GPU
API FastAPI + Strawberry GraphQL
ORM SQLAlchemy 2.0 async + psycopg 3
Database PostgreSQL 16 — dual databases
Monitoring Prometheus + Grafana
Reverse Proxy Traefik v3.1 — HTTPS, automatic TLS
